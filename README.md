# Привет, я Иван 👋

Разработчик Telegram- и VK-ботов и сайтов. Делаю продукты полного цикла в одиночку — от бота, который парсит контент и переписывает его через нейросети, до сайта, на который клиент в итоге записывается.

**Три бота ниже работают на серверах прямо сейчас** — это не черновики и не пет-проекты для резюме.
